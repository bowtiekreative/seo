OPERATORS
---------
IF       condition
THEN     true action
ELSE     false action
AND      all must pass
OR       valid alternatives
NOT      exclude
XOR      exactly one
FOR EACH controlled expansion
UNTIL    bounded loop
AT LEAST minimum
EXACTLY ONE unique owner/decision

ONE-PAGE RULE
-------------
IF same sense
AND same task
AND compatible answer structure
AND compatible result class
AND compatible next action
THEN same cluster and one canonical owner
ELSE split or test.
