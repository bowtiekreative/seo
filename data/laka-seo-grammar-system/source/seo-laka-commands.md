# LAKA SEO Pseudo-Commands

These commands are a compact notation for humans or agents. They are not tied to a specific software package.

## Define a program

```text
/seo
goal="<qualified business outcome>"
business="<business>"
offer="<offer>"
audience="<segment>"
conditions="<context>"
task="<verb + object>"
intent="<intent>"
cluster="<representative cluster>"
canonical="<URL>"
format="<task-native format>"
evidence="<proof>"
graph="<role and edges>"
next="<adjacent action>"
metric="<primary metric>"
constraints="<hard limits>"
```

## Expand a semantic territory

```text
/expand
concept="<parent concept>"
dimensions="parents,subtypes,synonyms,entities,attributes,relations,problems,causes,solutions,comparisons,questions,time"
audiences="<approved audiences>"
tasks="<approved task verbs>"
geographies="<approved locations>"
exclude="<wrong senses and audiences>"
```

## Cluster candidates

```text
/cluster
input="<candidate set>"
same_page_if="same sense AND same task AND compatible answer AND compatible next action"
split_if="different task OR different sense OR different necessary format OR real local/product difference"
output="canonical intent registry"
```

## Apply publication gates

```text
/gate
candidate="<candidate>"
require="demand AND distinct task AND business value AND information advantage AND technical feasibility AND maintainability AND measurement AND compliance"
else="merge OR section OR research OR defer OR reject"
```

## Run LAKA

```text
/laka
object="<SEO object>"
goal="<outcome>"
levels="Baseline,Minor,Major,Structural,Paradigm"
variables="Object,Conditions,Actions,Tools,Resources,Outcomes,Feedback,Constraints,Value,FailureMode"
descriptors="Magnitude,Rate,Direction,Scope,Depth,Duration,Frequency,Acceleration,Variability,Detectability,Reversibility,Propagation,Amplification,Accumulation"
```

## Create an experiment

```text
/experiment
id="<change ID>"
object="<object>"
laka="<level>"
if="<condition>"
then="<expected outcome>"
because="<mechanism>"
primary="<metric>"
guardrails="<metrics>"
baseline="<state>"
exposure="<minimum exposure>"
decision="<continue/expand/revise/reverse/escalate/retire>"
rollback="<rollback>"
```

## Audit technical eligibility

```text
/audit-technical
scope="<site/cohort/URL>"
states="access,status,render,robots,index,canonical,sitemap,links,depth,CWV,structured-data"
prioritize_by="affected business value × impact probability / effort and risk"
```

## Audit canonical ownership

```text
/audit-canonical
clusters="<cluster registry>"
detect="multiple owners OR unstable URL dominance OR divided value"
actions="keep,merge,reposition,retire"
```

## Generate a page brief

```text
/page
cluster="<cluster ID>"
audience="<audience>"
task="<task>"
canonical="<URL>"
format="<format>"
answer="<direct answer>"
entities="<entities>"
relations="<relations>"
evidence="<evidence>"
links="<in/out edges>"
next="<next action>"
metric="<primary metric>"
```

## Review a portfolio

```text
/review
period="<period>"
evaluate="business,demands,canonicals,assets,technical,authority,experiments"
decide="continue XOR expand XOR revise XOR reverse XOR escalate XOR retire XOR monitor"
update="scores,rules,gates,backlog"
```
